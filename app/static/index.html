Apply common edits and re-check. Paraphrasing and translation are the known weaknesses of text watermarks; they are not simulated here.

The UI uses the same REST API. Callers authenticate to the app with a Databricks OAuth token.

curl -s -X POST "$APP_URL/api/v1/detect" \
  -H "Authorization: Bearer $(databricks auth token -p PROFILE | jq -r .access_token)" \
  -H "Content-Type: application/json" \
  -d '{"text": "…", "include_tokens": false}'

Response fields: verdict (watermarked, not_detected, too_short), p_value, z_score, mean_g (mean per-token score on a 0–1 scale; 0.5 expected without a watermark), num_scored, key_id, checked_at, text_sha256 and an HMAC signature over the result. OpenAPI docs: /docs.
